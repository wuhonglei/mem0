## 关键发现

### 1. 完全相同 (>0.98) — 83 对

**主要成因**:

- **user/assistant 双重提取**: 同一对话中，user 说的内容和 assistant 总结的内容语义完全一致，被各存一条
- **同一问题多次询问**: 用户在不同 session 中问了相同问题，每次生成独立记忆
- **标点/空格差异**: 仅中文标点、空格、大小写不同（如 `Agent` vs `agent`）

### 2. 高度重复 (>0.95) — 108 对

**典型模式**:

- 同一事实的不同表述，信息量相近
- 浓缩版 vs 详细版（如 "清晖园是四大名园之一" vs 含门票价格的完整版）
- 英文 vs 中文描述同一事物（如深圳购房价格）

### 3. 中度重复 (>0.92) — 210 对

**典型模式**:

- 同一话题的不同角度，信息有交叉但也有新增
- 例：MarkdownHeaderTextSplitter 的 5 条记忆各侧重不同方面
- 例：中信银行加班的 4 条记忆覆盖不同组别细节

### 4. 轻度相似 (>0.90) — 233 对

**典型模式**:

- 同一领域的不同知识点（如 Langfuse 的 Trace/Observation 概念）
- 时间相近的不同天气记录（深圳不同日期的天气）
- 相关但不重复的技术讨论

## 清理建议

### 自动清理（零风险）

**条件**: similarity > 0.95
**策略**: 保留 text 较长的一条（信息量更大），删除较短的
**影响**: 删除 ~155 条记忆，清理后剩余 ~4500 条

### 半自动清理（低风险）

**条件**: 0.92 < similarity ≤ 0.95
**策略**: 生成报告供人工确认，优先合并为一条更完整的记忆
**影响**: 涉及 ~210 对，预计可再减少 100~150 条

### 人工审核

**条件**: 发现的事实冲突（儿子名字等）
**策略**: 核实正确信息，删除错误版本
